# Dkkf Launcher 0.4.3 — Discord Rich Presence

앱 ID: 1572459000841109654

Discord 데스크톱 앱의 로컬 IPC에 연결해 런처 준비 상태 또는 Minecraft 버전·로더·플레이 경과 시간을 표시합니다. 게임 시작/종료에 따라 상태를 갱신하며, Discord를 늦게 실행하거나 재시작해도 재연결을 시도합니다. 설정의 Discord Rich Presence 옵션은 기본 켜짐이며 게임 실행 중에도 즉시 끌 수 있습니다. 종료 및 끄기 시 활동을 비우고 연결을 닫습니다.

닉네임·인스턴스 이름·월드 이름·서버 주소·Microsoft 토큰은 전송하지 않습니다. Discord 봇/OAuth 토큰을 요구하지 않으며 Discord 사용자·메시지·서버 데이터를 요청하지 않습니다. 활동 표시는 Discord 클라이언트의 활동 공유 설정에도 영향을 받습니다.

사용자의 이전 요청대로 추가 자동 테스트 및 실제 Discord 상태 검증은 생략했습니다. TypeScript와 설치 파일 빌드만 수행합니다. 설치 파일과 체크섬만 공개합니다.

공식 IPC 참고: https://docs.discord.com/developers/topics/rpc
다운로드: https://dkkf.온라인.한국
