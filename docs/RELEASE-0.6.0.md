# Dkkf Launcher 0.6.0 — DKKF Fabric 서버 전용 구성

26.3 Fabric 모드팩을 가져오면 별도 설치 확인 없이 아래 파일을 준비합니다. 직접 만든 26.3 Fabric 인스턴스 및 기존 인스턴스의 실행 전에도 동일하게 적용합니다.

| 구성 | 서버 고정 버전 |
| --- | --- |
| TaCZ Reforged | 1.1.8+mc26.3 Fabric, CurseForge 파일 9263837 |
| Fabric API | 0.166.2+26.3 |
| 첨부 mod 3 (`trollvideo`) | 1.0.0, Fabric 26.3 |

DKKF HUD는 설치 파일에서 제외하고 설치 버튼을 제거했습니다. 적용 대상 인스턴스에 이미 활성 HUD가 있으면 먼저 모드 백업을 만들고 `backups/excluded-hud`에 보관하여 실행 대상에서 제외합니다. Paper 연동 플러그인 및 Locator Bar는 새 설치에 자동 추가하지 않습니다.

세 필수 모드는 `shared/server-profile.json`의 SHA-256 해시로 검증합니다. 기존 필수 모드가 서버 버전과 다르면 전체 모드 백업 후 고정 버전으로 맞춥니다. 비활성 필수 모드는 활성화합니다. 일반 모드·리소스팩·쉐이더팩·월드의 자동 업데이트는 수행하지 않습니다. 기존 그래픽 프리셋의 자동 추가도 중단했습니다.

다운로드 실패 시 기존 모드 변경 전에 중단합니다. 필수 모드가 준비되지 않으면 게임 실행을 중단합니다. 26.3 Fabric 이외의 모드팩은 가져오기를 거부하며 임의로 다른 로더로 변환하지 않습니다. 다른 로더의 기존 인스턴스는 서버 구성 대상에서 제외합니다.

TaCZ 및 Fabric API는 설치 시 공식 배포 CDN에서 내려받으며 CurseForge API 키 입력 없이 준비됩니다. mod 3만 런처 설치 파일에 포함됩니다. TaCZ JAR는 런처 설치 파일이나 공개 다운로드 서버에 재배포하지 않습니다. 서버 구성과 일치하는 다른 모드팩의 의존성 호환성 및 실제 성능 향상은 보장하지 않습니다.

## 서버에 적용

서버는 Paper에서 Fabric 26.3으로 별도 전환해야 합니다. Java 25 이상, Fabric Loader 0.20.1과 위 세 모드를 사용하세요. 준비된 서버용 파일은 로컬 `release/0.6.0/server-mods` 폴더에 있습니다. 서버를 정지하고 월드·설정·플러그인을 먼저 백업한 뒤 새 Fabric 서버의 `mods` 폴더에 세 JAR를 넣으세요. Paper 플러그인은 Fabric 서버에서 그대로 실행되지 않습니다. 서버 파일 교체·실행·월드 변환은 이번 작업에서 수행하지 않았습니다.

## Windows 서명

사용 가능한 코드서명 인증서 또는 서명 서비스 설정을 찾지 못해 이번 설치 파일은 Authenticode 미서명입니다. 자체 서명 인증서를 만들어 신뢰된 인증처럼 표시하지 않습니다. 업데이트 매니페스트의 Ed25519 서명은 별개로 유지합니다.

유효한 인증서를 준비한 경우 빌드 세션의 환경 변수 `CSC_LINK`(PFX 경로)와 `CSC_KEY_PASSWORD` 또는 인증서 저장소의 `DKKF_SIGNING_CERT_SHA1`로 서명 빌드를 구성할 수 있습니다. 설정 시 패키징이 코드 서명을 필수로 요구하며, 서명 실패를 무서명 성공으로 처리하지 않습니다. 키·암호는 소스와 문서에 기록하지 마세요.

TypeScript 및 Windows 설치 파일 빌드를 수행했습니다. 사용자 요청에 따라 추가 테스트·실제 게임·서버 실행은 생략했습니다.

## 서버 자동 접속

런처에서 26.3 Fabric 게임을 실행하면 Minecraft Quick Play 옵션으로 `dkkf.mc-hosting.xyz`에 바로 접속합니다. 모드팩의 다른 서버/싱글플레이/Realms 접속 옵션은 제거하여 목적지 충돌을 막습니다. 새 인스턴스는 26.3 Fabric만 생성하며, 다른 버전/로더의 기존 인스턴스는 서버 전용 런처에서 실행하지 않습니다. Locator Bar는 새 기본 구성에서 제외하며 이미 사용자가 설치한 Locator Bar는 자동 삭제하지 않습니다. 실제 서버 가용성·접속·월드 로딩은 테스트하지 않았습니다.
