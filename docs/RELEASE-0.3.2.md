# Dkkf Launcher 0.3.2 — 런처 자동 업데이트

다운로드: https://dkkf.온라인.한국

0.3.2부터 공식 업데이트 서버 주소와 검증용 Ed25519 공개키를 기본 설정합니다. 이전 버전의 주소/키가 모두 비어 있으면 한 번 자동 설정하며 자동 업데이트를 켭니다. 사용자가 설정한 별도 서버/키와 이후의 끄기 선택은 보존합니다.

## 동작

- 시작 시 및 5분마다 새 런처 버전을 확인합니다. 게임 실행/설치 중에는 확인·다운로드를 미룹니다.
- 공개 서버의 서명된 stable.json을 검증하고 새 버전의 설치 파일을 자동 다운로드합니다. SHA-256 및 크기를 검증합니다. 이미 검증된 캐시는 재사용합니다.
- 다운로드가 완료되면 게임 종료 후 런처를 닫을 때 검증된 설치 프로그램에 `/S --updated`를 전달합니다. 게임 실행 중 강제로 업데이트하지 않습니다. 설치 직전 서명과 해시를 다시 확인합니다.
- 설정에서 끌 수 있습니다. 기존 수동 확인·다운로드·설치 버튼도 유지합니다. 모드 자동 업데이트는 하지 않습니다.
- 0.3.1 이전 런처는 배포 설정이 비어 있어 이 기능을 받을 수 없습니다. **0.3.2를 한 번 직접 설치한 뒤부터** 이후 자동 업데이트가 동작합니다.

## 배포 운영

공개 다운로드 사이트의 `/stable.json`에서 서명된 업데이트를 제공합니다. 관리자 인증으로 파일을 업로드한 뒤 게시하면 Worker가 저장소의 파일/크기/해시 메타데이터를 확인하고 매니페스트에 서명합니다. 개인키는 Sites의 secret 환경 변수에만 저장하며 런처/소스 ZIP에는 공개키만 포함합니다. Beta 채널은 릴리스가 없으면 404를 반환하며 stable로 임의 대체하지 않습니다.

Ed25519 매니페스트 서명과 Windows Authenticode는 별개입니다. Windows 코드서명과 설치 후 자동 롤백은 제공하지 않습니다. 실제 NSIS 자동 업그레이드 실행은 사용자 설치 환경에서 미검증입니다. 테스트는 설치 프로그램 실행 전달을 모킹하여 실제 시스템에 설치하지 않습니다.

## 검증

29개 자동 테스트 통과. 기존 보안/인증/인스턴스 회귀 검사와 기본 업데이트 설정 이전, 사용자 끄기/별도 신뢰키 보존, 검증 캐시 재사용, 파일 변조 차단, 신뢰키 변경 차단 및 무인 설치 인수 전달을 확인했습니다. 실제 공개 서명 및 파일 다운로드 검증과 패키지 UI 검증 결과는 배포 검증 기록에 별도로 보관합니다.
