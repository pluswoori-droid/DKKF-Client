# Dkkf Launcher 0.6.3

TaCZ Reforged와 mod 3(trollvideo)를 Windows·Android 자동 설치 구성에서 제거했습니다. 새 인스턴스 생성, 모드팩 가져오기, 기본 구성 재시도 및 게임 실행 전 준비에서 두 모드를 더 이상 자동 설치·교체·활성화하지 않습니다. 이미 인스턴스에 설치된 두 모드와 사용자가 가져오는 모드팩의 파일은 삭제하지 않습니다.

남은 기본 구성은 Fabric API, Xaero’s Minimap, Dkkf Loot Xaero Client입니다. Java 자동 설치, 서버 자동 접속, HUD·Locator Bar 제외 정책은 유지합니다. Windows 설치 파일에 mod 3 번들을 포함하지 않습니다.

Android는 같은 목록 변경을 0.1.2-preview 로컬 빌드와 GitHub 소스에 반영합니다. 사이트의 Android 다운로드는 계속 차단합니다.

사용자 요청에 따라 게임·기기 실행 테스트는 생략합니다. 빌드 및 설치 파일의 구성만 확인합니다.
