# Dkkf Launcher 0.5.2 — Microsoft 앱 식별자 표시 제거

Microsoft 로그인에 필요한 앱 식별자는 메인 프로세스의 내부 설정에서 사용합니다. 설정 화면의 Client ID 입력란을 제거하고, 화면으로 보내는 상태 데이터에서도 실제 값을 제외했습니다. 설정 저장 시 내부 값은 유지되므로 로그인 구성이 빈 값으로 덮어써지지 않습니다.

문서의 실제 Client ID 표기를 제거했습니다. 배포 패키지는 소스맵을 포함하지 않습니다. 전체 소스 ZIP은 공개하지 않으며 설치 파일과 체크섬만 배포합니다.

Client ID는 비밀 키가 아닌 공개 앱 식별자입니다. 데스크톱 앱의 로그인 요청 및 설치 파일 분석으로 식별될 수 있으므로 이 변경이 Client ID를 비밀로 만드는 것은 아닙니다. 클라이언트 시크릿을 데스크톱 앱에 추가하지 않습니다.

TypeScript와 프로덕션 패키징을 수행했습니다. 사용자 요청에 따라 추가 테스트 및 실제 로그인 실행은 생략했습니다.
