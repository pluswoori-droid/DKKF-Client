# Dkkf Launcher 0.4.4

## 필수 의존성

이미 설치된 모드를 유지할 때도 하위 필수 의존성을 확인합니다. 새 인스턴스, JAR 가져오기, 게임 실행 전에 누락 의존성을 준비하며 설치된 모드의 의존성 확인/복구 버튼으로 다시 실행할 수 있습니다. 로컬 JAR는 SHA-512 해시로 공식 Modrinth 배포본을 식별해 필수 의존성 정보를 조회합니다. Fabric API에 내장된 모듈 및 provides 별칭을 인식합니다. 알려진 공통 라이브러리의 누락도 확인합니다.

기존 모드 자체를 자동 업데이트하지 않습니다. 사용자가 비활성화한 필수 모드나 고정 버전 충돌은 자동 교체하지 않고 안내합니다. 공식 배포 정보가 없는 사설 JAR의 알 수 없는 의존성은 제작자 안내가 필요할 수 있습니다.

## 런처 업데이트

무인 설치 대신 설치 프로그램이 보이도록 열며 현재 런처 경로를 설치 위치로 전달합니다. OS 실행 차단에 대한 Shell 실행 대체 경로를 추가했습니다. 설치 실행 오류가 나면 런처를 닫지 않고 오류 및 파일 폴더 열기를 제공합니다. 짧은 시간 내 설치 프로그램이 실패 종료되는 경우를 감지하고 로그를 남깁니다.

확인·다운로드 중복 요청을 합치고 검증된 캐시를 재사용합니다. 서명된 매니페스트와 파일을 함께 보관해 재시작 후 준비 상태를 복구하며 이전 설치가 완료되지 않았으면 재시도를 안내합니다. 서명/해시/크기를 설치 직전에 다시 검사합니다. 자동 다운로드 상태도 업데이트 화면에 즉시 표시합니다.

기존 버전의 종료/설치 흐름에 문제가 있으면 이번 0.4.4는 사이트에서 직접 설치하세요. 실제 Windows 설치 프로그램 업그레이드는 이번 작업에서 실행하지 않았습니다.

## 검색

모드·리소스팩·쉐이더팩 검색에 이전/다음 페이지 및 전체 결과 수를 추가했습니다. 설치된 모드는 이름·ID·파일명·제작자·버전으로 즉시 필터링할 수 있습니다.

## 검증과 공개 범위

사용자의 이전 요청으로 추가 자동 테스트·UI 테스트·실제 게임/업그레이드 실행은 생략했습니다. TypeScript와 배포 빌드만 수행합니다. 설치 파일·체크섬만 공개하며 소스 ZIP은 비공개입니다.
