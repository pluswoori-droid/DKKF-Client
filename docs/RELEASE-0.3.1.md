# Dkkf Launcher 0.3.1

공개 다운로드: https://dkkf.온라인.한국

- 계정 탭의 활성 계정과 연결된 계정 목록에 캐시된 Minecraft 스킨 얼굴을 표시합니다. 홈과 같은 얼굴 컴포넌트를 사용하며 스킨 새로고침 버튼을 제공합니다. 얼굴 다운로드 실패 시 이니셜을 표시합니다.
- 모드 검색에서 현재 인스턴스에 설치된 프로젝트는 opacity 0.48로 흐리게 표시하고 `설치됨` 배지를 붙입니다. 마우스/키보드 포커스에서는 opacity 0.78로 세부 정보를 읽을 수 있습니다.
- 비활성 모드도 설치 상태로 표시합니다. 설치·삭제 후 상태를 다시 읽으며, 상세 화면에서 동일 버전 중복 설치 버튼은 비활성화합니다.
- 설치 여부는 실제 로컬 모드 목록의 플랫폼·프로젝트 정보를 기준으로 비교합니다. 출처 정보가 없는 임의 로컬 JAR는 검색 프로젝트와 임의로 이름을 비교하지 않으므로 배지가 표시되지 않을 수 있습니다.

## 검증

TypeScript/프로덕션 빌드 및 27개 회귀 테스트 통과. 실제 패키지의 기본 시작 및 미인증 업로드 센터 숨김을 확인했습니다. 별도 테스트 창의 합성 프로필·모드 fixture로 계정 얼굴 이미지 로드, 설치/비활성 배지, 투명도, 설치 직후 갱신과 동일 버전 설치 제한을 확인했습니다. 실제 계정으로 로그인한 결과는 아닙니다. renderer 오류 0.

근거: `docs/verification/packaged-ui-0.3.1.json`. HUD와 Locator Bar 번들은 0.3.0 배포와 동일합니다. 실제 계정 인증·인증 게임 실행 및 Windows 설치/제거 테스트에 관한 기존 검증 한계는 [0.3.0 문서](RELEASE-0.3.0.md)를 참고하세요. Windows 코드서명은 없습니다.
