# Dkkf Launcher 0.5.0

Paper 26.3 전용 DKKF Server Bridge와 Fabric 26.3 클라이언트 모드를 추가했습니다. 서버 기능 목록과 권한이 확인될 때만 F10 메뉴에서 최대 18개 구현 기능을 켤 수 있습니다. LiquidBounce 전체 기능을 포함하지 않습니다.

설정에서 연동 모드 자동 추가를 끌 수 있고 Paper 서버 플러그인 JAR를 저장할 수 있습니다. 기존 인스턴스는 실행 전에 누락된 연동 모드만 추가하며 다른 번들 모드를 강제 복원하거나 기존 모드를 자동 업데이트하지 않습니다.

[서버 설치·권한·기능 목록·미구현 항목](SERVER-BRIDGE.md)을 확인하세요. 서버에 플러그인을 넣고 완전히 재시작해야 합니다. 이 작업은 실제 DKKF 서버에 플러그인을 배포하지 않았습니다.

Paper/Fabric Java 컴파일, TypeScript 및 배포 빌드만 수행하며 추가 테스트와 실제 서버·게임 실행은 사용자 요청대로 생략했습니다. 공개 아티팩트는 런처 설치 파일과 체크섬뿐입니다. 서버 JAR는 설치 파일 내부에서 내보내며 전체 소스 ZIP은 공개하지 않습니다.
