# Dkkf Launcher 0.5.1 — HUD 화면 가림 개선

- HUD 0.3.1: 기본 표시를 FPS·핑·좌표 3개, 크기 80%로 간소화했습니다. 배경 불투명도를 낮췄습니다.
- F7로 HUD 전체 표시/숨기기를 전환하고 프로필별로 저장합니다. F1 HUD 숨기기와 메뉴·채팅·인벤토리 화면에서도 표시하지 않습니다.
- F8 편집기에 한국어 버튼과 ‘간소화’를 추가했습니다. 간소화 버튼은 현재 프로필의 배치·크기·표시 항목을 초기화합니다. 나머지 항목도 편집기에서 켤 수 있습니다.
- 기존 기본 배치를 그대로 사용 중인 경우만 간소화 배치로 전환합니다. 직접 편집한 프로필은 유지합니다.
- 기존 인스턴스는 게임을 종료한 후 인스턴스 설정에서 ‘DKKF HUD 설치 / 업데이트’를 눌러 HUD를 갱신해야 합니다. 런처 업데이트만으로 기존 HUD JAR를 교체하지 않습니다.

Java 컴파일과 런처 패키징을 수행했습니다. 사용자 요청으로 추가 테스트 및 실제 게임 실행은 생략했습니다.
