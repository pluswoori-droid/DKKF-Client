# Dkkf Launcher 0.4.1

인스턴스 편집 메뉴가 본문과 겹치는 문제를 수정했습니다. 앱 전체 사이드바/상단 바의 전역 aside/header 스타일을 전용 클래스로 제한하여 인스턴스 내부 메뉴·헤더에 고정 폭, 여백, 높이가 적용되지 않도록 했습니다. 작은 창에서의 사이드바 규칙도 앱 전용으로 제한하고 긴 인스턴스 이름의 줄바꿈을 보완했습니다.

사용자의 이전 요청에 따라 추가 테스트는 생략하고 TypeScript 및 배포 빌드만 수행합니다. 설치 파일과 체크섬만 공개하며 소스 ZIP은 공개하지 않습니다.

다운로드: https://dkkf.온라인.한국
