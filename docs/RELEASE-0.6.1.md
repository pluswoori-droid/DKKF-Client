# Dkkf Launcher 0.6.1

설정 → 게임 환경 → 언어에서 한국어, English, Монгол хэл을 선택할 수 있습니다. 선택 즉시 로컬 설정에 저장하고 화면 문구와 날짜 표기를 변경합니다. 홈·인스턴스·콘텐츠·모드팩·업데이트·계정·설정 화면과 기본 확인 대화상자를 번역했습니다. 사용자 이름, 인스턴스 이름, 외부 모드 설명 및 기술 로그는 원문을 유지합니다. 번역 사전에 없는 외부 오류는 원문으로 표시합니다.

클라이언트 자동 설치 목록에 사용자가 제공한 Dkkf Loot Xaero Client 2.0.2를 추가했습니다. 필수 Xaero's Minimap 26.6.2도 공식 Modrinth 파일에서 내려받으며 XaeroLib 1.8.5는 미니맵 JAR에 내장되어 있습니다. Fabric API와 함께 모드 ID·파일 해시를 검증합니다. 두 모드는 클라이언트용으로 추가하며 서버용 ZIP에는 넣지 않습니다.

홈 배너는 현재 남아 있는 인스턴스의 유효한 lastPlayed 중 가장 최근 값을 기준으로 이름·버전·로더·RAM 설정과 실행 버튼을 표시합니다. 플레이 기록이 없으면 선택한 인스턴스, 없으면 첫 인스턴스를 표시하며 인스턴스가 전혀 없으면 생성 버튼을 보여 줍니다. 인스턴스 이름은 번역하지 않습니다.

기존 TaCZ·Fabric API·mod 3, 서버 자동 접속, Locator Bar·HUD 기본 설치 제외 및 Client ID 화면 표시 제외는 유지합니다. 새 클라이언트 모드까지 포함하는 준비 작업은 설치/실행 전에 자동 수행합니다.

Windows 코드서명은 인증서가 없어 적용하지 않았습니다. 업데이트 매니페스트 서명은 유지합니다. TypeScript 및 프로덕션 빌드를 수행했으며 사용자 요청으로 추가 테스트와 게임·서버 실행은 생략했습니다.
