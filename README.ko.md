# Dkkf Launcher 0.6.1

DKKF 서버 전용 Minecraft 26.3 Fabric 런처. 모드팩 설치 시 TaCZ Reforged·Fabric API·첨부 mod 3를 확인 창 없이 자동 준비하고 DKKF HUD는 제외합니다.

[0.6.1 변경 사항](docs/RELEASE-0.6.1.md) · [서버 설치 안내](docs/RELEASE-0.6.0.md) · [공개 다운로드](https://dkkf.온라인.한국)

이전 버전의 설명은 아래에 남아 있으며 현재 동작은 0.6.0 릴리스 문서를 우선합니다.


Minecraft Java Edition용 Windows 런처입니다. 제작 기준: Minecraft 26.3 Fabric / Java 25 이상.

[공개 다운로드](https://dkkf.온라인.한국) · [변경·사용법·제한](docs/RELEASE-0.4.0.md) · [빌드](BUILD.md) · [개인정보](PRIVACY.md)

인스턴스의 개요·콘텐츠·월드·모드팩·설정을 한곳에서 관리합니다. 모드뿐 아니라 리소스팩·쉐이더팩 검색/설치/활성화와 Java 월드 ZIP·폴더 가져오기를 제공합니다.

새 인스턴스 또는 기존 인스턴스 첫 실행 전에 호환 기본 모드·그래픽 구성을 한 번 준비합니다. 기존 파일은 자동 업데이트하거나 강제로 교체하지 않습니다. Fresh Moves는 현재 26.3 배포본이 없어 지원 대기로 표시합니다. 설정에서 기본 구성을 끌 수 있으며 가져온 모드팩은 원래 구성을 유지합니다.

0.3.2 이상은 서명된 런처 자동 업데이트로 받을 수 있습니다. 그 이전 버전은 한 번 직접 설치하세요.

사용자 요청으로 이번 추가 테스트는 생략했습니다. 배포 빌드만 수행하며 실제 게임 조합·쉐이더 렌더링·월드 열기는 미검증입니다. Windows 코드서명은 없습니다.
