# Security reporting

Contact: [pluswoori@gmail.com](mailto:pluswoori@gmail.com)

For a suspected vulnerability involving account tokens, unsafe downloads, archive paths, IPC, updates or code execution, email the project contact with the affected version, a concise description, expected/actual behavior and reproduction steps using synthetic data where possible. Do not include live credentials, private keys, `.vault` files, personal account databases or unredacted game logs. Do not place sensitive exploit details or other users' information in a public issue.

The project has not established a response-time commitment, bounty program or independent security certification. The supplied Windows builds are development builds without Authenticode signing. Source availability and passing tests do not establish production readiness.

For details of current safeguards, see [authentication reviewer notes](docs/AUTHENTICATION.md), [privacy notice](PRIVACY.md) and [test report](TEST-REPORT.md). Third-party mods execute with the game's privileges and are not sandboxed by DKKF. Never assume that a matching file hash proves that a mod is harmless.
